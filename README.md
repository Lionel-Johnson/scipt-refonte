# scipt-refonte

Site statique HTML/CSS/JavaScript du SCIPT INTERNATIONAL.

## Identité visuelle

`assets/charte-scipt.css` applique la charte graphique officielle 2025 après les styles historiques. Palette : marine `#071B41`, bleu `#123D8D`, or `#F5B800`, blanc `#FFFFFF`. Le rouge `#B5121B` reste réservé aux communications urgentes ou promotionnelles. Titres en Lora, interface et textes en Poppins, avec polices système de repli.

Les fichiers `assets/logo-university-officiel.jpg` et `assets/logo-academy-officiel.jpg` proviennent directement des déclinaisons officielles présentées dans la charte. La version University apparaît sur les programmes universitaires, la version Academy sur les formations professionnelles. La page d’accueil et la page institutionnelle conservent le blason racine.

Le PDF de la charte, marqué confidentiel, n’est pas inclus dans ce dépôt public. Les photographies historiques du site restent à auditer avec l’équipe de communication avant validation finale, conformément aux critères d’authenticité de la charte.
